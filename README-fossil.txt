If you are reading this on Github or a git clone,
please note that this git repository is exported
from a fossil repository.

This means that pull requests will not work and will not be accepted.

The local command to create this git repository was:

fossil git export \
       /Users/davidevans/mac/.fossil-git-mirrors/netpbm-blank-icon.git \
       --mainbranch main \
       --autopush git@github.com:snowflake/netpbm-blank-icon.git
