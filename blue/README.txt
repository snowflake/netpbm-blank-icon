This folder is for a demonstration of an icon that does not
display on macOS Safari and Preview.

Safari is a web browser. Preview is an image viewer. Preview knows
about lots of image formats.

Files in this directory
-----------------------

Makefile - used to generate the program and icons.
blue.c - source code for the blue program. The blue program generates
         blue.ppm
sample-blue.ico - an icon generated by the creator of this repository.
sample-blue.ppm - a PPM file generated by the creator of this repository.
sample.log - logfile by the creator of this repository.

Creating the .ico file
----------------------

make all
     To generate the program.

make ico
     To create blue.ico and process the ico back to a pam file.

make clean
     To clean all the generated files.

Message from winicontopam
--------------------------

Whenever I see this message:

"mismatch in header and image bpp value(8 vs. 32)
winicontopam: image  0: All pixels are nominally coded in the
transparency map as fully transparent, which is defined by the
format to mean they are all opaque."

seems to indicate the the icon will not display on Safari and Preview,
although it will be OK on Firefox and Google Chrome. Since I'm seeing
a 35% failure rate for icons originating from Inkscape svg files, and also
this program, it seems unlikely that there is a bug in Apple code, more
likely it is being cautious about what it displays.
